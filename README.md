# Portfólio Pessoal

Site estático de portfólio em português, com visual moderno e responsivo.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Troque o nome, contatos, experiência e projetos pelos seus dados.
3. Se quiser, publique em qualquer hospedagem estática.

## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: visual e responsividade.
- `script.js`: animações e troca de destaque da função.
